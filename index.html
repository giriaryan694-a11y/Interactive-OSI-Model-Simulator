How the OSI Model Works

Encapsulation: Data moves down the layers on Computer 1, each layer adding headers or converting data: TCP/UDP headers, IP addresses, MAC addresses, and bits.

Transmission: Packet travels across the network from Computer 1 → Computer 2. Packet changes visually at each layer with emojis.

De-Encapsulation: Data moves up the layers on Computer 2, each layer removing headers and decoding data, until Application Layer receives the message.

Interactive Features: Users can type a message, choose TCP or UDP, and see all transformations: Application → Presentation → Session → Transport → Network → Data Link → Physical.
